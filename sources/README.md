# Портфолио Екатерины Зайцевой

Статический сайт с 19 проектами. Его можно перенести на любой хостинг, который раздаёт HTML, CSS, JavaScript и изображения. Папка `dist` — готовый сайт.

## Что редактировать

- `portfolio-content.json` — названия, описания, порядок проектов, категории и цвета карточек.
- `image-sources.json` — выбранные страницы каждого проекта, их подписи и расположение исходных файлов на этом компьютере.
- `dist/assets/*.webp` — подготовленные изображения для сайта. Они входят в проект, поэтому сайт работает и без доступа к исходной папке Design.
- `dist/assets/style.css` — базовые стили; `yaeger-direction.css` — текущая визуальная тема; `portfolio-extensions.css` — карточки, страницы проектов и общая рамка просмотра.
- `build_portfolio.py` — пересобирает главную и страницы проектов из двух JSON-файлов. После изменения текста запустить `python3 build_portfolio.py`.
- `naglyadno-story.html` и `dist/assets/naglyadno-story.css` — подробная история проекта «Наглядно». Сборка подставляет в неё просмотр лендинга.
- `naglyadno-figma-assets.json` — перечень изображений, взятых напрямую из Figma, с ID исходных фреймов. Копии изображений находятся в `dist/assets/naglyadno-case/` и не зависят от временных ссылок Figma.
- `snk-story.html` и `dist/assets/snk-story.css` — история магазина SNK. Сборка подставляет в неё шесть прокручиваемых макетов.
- `snk-figma-assets.json` — перечень внутренних страниц SNK, экспортированных из Figma, с ID фреймов и размерами копий. Главная и мобильный блог взяты из локальных файлов, перечисленных в `image-sources.json`.
- `capservice-story.html` и `dist/assets/capservice-story.css` — подробная история CapService. Все изображения проекта экспортированы из Figma и хранятся вместе с сайтом; их фреймы перечислены в `capservice-figma-assets.json`.
- `kilev-story.html` и `dist/assets/kilev-story.css` — история сайта Kilev Lab. Главная и её мобильная версия взяты из локальной папки Design; страница айдентики и мобильное портфолио экспортированы из Figma. Источники указаны в `image-sources.json`.
- `iceflow-story.html` и `dist/assets/iceflow-story.css` — история сайта Iceflow. Десктопная и мобильная версии взяты из экспортов в папке Design; исходные пути указаны в `image-sources.json`.
- `branding-stories.json` и `dist/assets/branding-story.css` — структура и оформление кейсов RENOM и Status Compliance. Изображения, подписи и ссылки на Figma перечислены в `image-sources.json`.
- `3r-branding-section.html` и `dist/assets/3r-story.css` — раздел фирменного стиля внутри существующего кейса 3R Agency. Выбранные страницы гайдбука указаны в `image-sources.json`; полный PDF сохранён в `source-materials/3r-agency/guidebook.pdf`.
- `source-materials/renom/` — полные экспорты разделов брендбука и презентации из Figma. `source-materials/status-compliance/brandbook.pdf` — сохранённый PDF брендбука. Эти файлы нужны для будущего редактирования и не входят в опубликованную папку `dist`.

Для локального просмотра раздать папку `dist` любым статическим сервером. На компьютере с Python: `python3 -m http.server 8765 --directory dist`, затем открыть `http://127.0.0.1:8765/`.

## Текущий этап

Это первая подборка работ для просмотра. Тексты большинства проектов черновые; описания «Наглядно», SNK, CapService, Kilev Lab, 0not1, Iceflow, RENOM и Status Compliance дополнены сведениями заказчицы и материалами макетов. Контакт пока отсутствует. В подборке намеренно нет Volkov и разрезанных файлов Split. Для Get Your Phuket взята зелёная версия; Gold не добавлена. Yodometics вынесен из SNK в отдельный проект. Несколько страниц большого сайта представлены как один проект с отдельными окнами просмотра, а брендбуки — как подборка разворотов и применений.

Длинные экспорты переведены в WebP и уменьшены до разумного размера. Короткие обложки загружаются на главной, полные страницы — внутри проектов. Это ускоряет загрузку, особенно мобильной версии «Наглядно». Оригиналы пользователя остаются в папке `Design/Portfolio/Web-sites portfolio`; точные пути сохранены в `image-sources.json`. Внутренние страницы SNK пока экспортированы из Figma с ограничением 1800 пикселей по длинной стороне; их можно заменить более чёткими копиями без изменения структуры страницы.

## Публикация и перенос

Текущая публикация: https://ekaterina-zaitseva-portfolio-2026.pleural-ramble4rgiru.chatgpt.site . Параметры Sites находятся в `.openai/hosting.json`. Для другого хостинга достаточно загрузить содержимое `dist` в корень сайта и привязать домен у выбранного провайдера. Учётные данные и секреты в этой папке не хранятся.
